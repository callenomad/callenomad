# CalleNomad (callenomad.com)

> **Street Spanish for Digital Nomads**  
> 1-on-1 tactical Spanish coaching built for location-independent workers living and traveling across Latin America and Spain.

---

## 🎯 Grounded Business Model

Based on the official business plan:

1. **Free 20-Minute Fluency Audit**
   - Direct qualification call via Calendly (`https://calendly.com/callenomad-info/20min`) to diagnose speaking bottlenecks and run real-world street simulations.

2. **The 50-Minute Tactical Blueprint**
   - **10 Min**: High-yield street slang & local filler words.
   - **20 Min**: Real-world roleplay (taxi drivers, landlords, waiters, merchants).
   - **15 Min**: High-stress scenarios & aggressive accent tuning.
   - **5 Min**: Real-world street homework missions.

3. **Core Programs & Transparent Pricing**
   - **The Quick Fix: First Week Survival** — **$129 USD** (2 Weeks / 3 Live Sessions)
   - **The Flagship: Street Smart Bootcamp** — **$399 USD** (6 Weeks / 6 Live Sessions + WhatsApp Voice Coaching)
   - **The VIP Local Insider** — **$1,099 USD** (12 Weeks / 24 Live Sessions + Live Text Support)

4. **Interactive Dialect & Slang Lab**
   - Real street codes across 4 major nomad hubs:
     - 🇲🇽 **Mexico City (CDMX)**: Chilango slang (*"¿Qué onda carnal?", "con copia", "ando en home office"*)
     - 🇨🇴 **Medellín**: Paisa rhythm (*"¿Me regala...?", "camellar", "parche", "chimba"*)
     - 🇦🇷 **Buenos Aires**: Porteño & Lunfardo (*"Che, ¿cómo andás?", "voseo", "billete dólar"*)
     - 🇪🇸 **Madrid**: Castizo directness (*"¿Tenéis wifi?", "contrato de temporada", "mola mazo"*)
   - Native audio pronunciation via Web Speech Synthesis API and 1-click clipboard copy.

## 🚀 Running Locally

Open `index.html` in your browser:
```bash
open index.html
```

Or run a local server:
```bash
python3 -m http.server 8000
```
Visit `http://localhost:8000`.
